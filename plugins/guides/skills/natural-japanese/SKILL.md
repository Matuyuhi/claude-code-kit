# natural-japanese — 言葉遣いの見直し

英語で考えた内容を日本語に直す時に、開発者が普段使わない語が混ざる。ユーザーに実際に指摘された語と、同じ型の語をここに集める。語の分類は nanaism/yomiyasu（MIT）の「直訳語」の考え方を参考にした。

## 判断の問い

その語を、開発者が同僚に口頭で言う時に使うか。

- 使う → 残す
- 使わない → その分野で普段使う呼び名に替える

同じ repo の他の md で使われていることは、残す理由にしない。AI が書いた文書の語が次の文書に移っているだけのことが多い。

## 直す型

### 1. 英語の術語を漢字 1 字に当てた語

| 書いてしまう語 | 元の英語 | 書く語 |
|---|---|---|
| 版（版を上げる・古い版・版数・版違い） | version | バージョン |
| 頭（ファイルの頭・一覧の頭） | head | 先頭 / 冒頭 |
| 枝（修正の枝） | branch | ブランチ |
| 題（PR の題） | title | タイトル |
| 印（lint の印） | mark | 指摘 / 目印 / マーカー |

### 2. 英語の術語を 2 字以上の漢語に当てた語

| 書いてしまう語 | 元の英語 | 書く語 |
|---|---|---|
| 根因 | root cause | 根本原因 |
| 基準線 | baseline | ベースライン |
| 時間窓 | time window | 時間帯 |
| 背景実行 | background job | バックグラウンド実行 |
| 回帰（不具合の意味で） | regression | デグレ / リグレッション |

### 3. 会話で言わない硬い語

| 書いてしまう語 | 書く語 |
|---|---|
| 推敲する・推敲用 | 文章を見直す・見直し用 |
| 前の版（文面の書き直しの意味で） | 前回の文面 / 修正前 |

この表は指摘を受けるたびに足す。推測で語を増やさない。

### 4. 物を人のように動かす言い方

機械やシステムが主語なのに「拾う」「響く」「効く」と書くと、何が起きるのかが読めない。何がどうなるかを書く。

- 「翌朝の再送ジョブが拾います」→「翌朝の再送ジョブがもう一度送ります」
- 「全店舗に響きます」→「全店舗でレジの表示が遅くなります」

## 残す言い方

- 定着した「〜版」: 最新版・旧版・安定版・修正版・パッチ版・日本語版・初版・改訂版
- 種類を指す「〜版」: String 版・arm64 版・Liquid Glass 版
- 定着した言い方: テストが通る・キャッシュが効く・回帰テスト・依存先
- 固有名詞・コード・コマンド・引用した原文

## 直し方

1. 指摘された語を、この会話の以後の文章で使わない
2. 同じ型の語が直前の文章に無いかを探して、一緒に直す
3. 語を 1 つ替えるだけで文が不自然なら、誰が何をどうするかが読める文に書き直す
4. 何を指すか分からない語は、広い語（影響する・関わる）に替えてごまかさず、指すものを確かめる
5. 新しく指摘された語は、型 1〜3 の表に足すことをユーザーに提案する

## 書き終えた後の点検

- 「版」を検索する。残っているのは「残す言い方」に当たるものだけか
- 型 1〜3 の表の「書いてしまう語」が無いか
- 声に出して読んで、同僚に言わない語が無いか
